# Primeros pasos

1. [Instala la extensión](/es/installation) y pulsa su icono para abrir los ajustes.
2. En modo básico, elige OpenAI, Anthropic o Google e introduce tu clave API. El proveedor cobra el uso por separado.
3. Elige el idioma de destino o escribe uno personalizado. Los cambios se guardan automáticamente; espera la confirmación.
4. Selecciona texto en una página HTTP o HTTPS y pulsa el botón **Traducir** que aparece cuando el detector local reconoce un idioma distinto al de destino.

El modo avanzado permite otros [proveedores](/es/providers), Ollama local, modelos personalizados y controles de razonamiento. Consulta [Uso](/es/usage) para conocer las diferencias con el menú contextual.
