# استكشاف الأخطاء وإصلاحها

- حمّل `dist/chrome/` أو `dist/firefox/manifest.json` بدل المصدر. يتطلب Firefox الإصدار 142 أو أحدث. أعد تحميل الإضافة والصفحة بعد البناء وتحقق من تأكيد الحفظ.
- استخدم URL كاملًا أو أعد نقطة الاتصال الافتراضية. استخدم HTTPS للخدمات البعيدة. لأخطاء 401/403 تحقق من المفتاح والصلاحيات والفوترة.
- حدّث النماذج أو أدخل معرّفًا متاحًا لحسابك. عطّل تجاوز الاستدلال إذا سبب خطأ. عند ظهور «API returned no translation text»، جرّب نموذجًا آخر أو نصًا أقصر. تُعاد بعض الاستجابات الفارغة دون بث.
- انتظر تجدد الحصة أو غيّر النموذج. ترجمة الصفحات ترسل عدة طلبات، وتفصل فترات انتظار بين المحاولات. يلغي **إيقاف** التنفيذ الحالي.
- شغّل Ollama ونزّل نموذجًا عبر `ollama pull llama3.2` واستخدم `http://localhost:11434`. عند رفض المصدر اضبط `OLLAMA_ORIGINS` وأعد التشغيل. يسمح `OLLAMA_ORIGINS="*" ollama serve` بجميع المصادر.
- إن غاب الزر، تحقق من الإعداد واللغات. استخدمه لتطبيق لغة الهدف المتقدمة والتعليمات الإضافية. أعد تحميل الصفحة المترجمة جزئيًا.

يضيف تصحيح الأخطاء تفاصيل إلى الأخطاء. قد تتضمن وحدات التحكم مفاتيح ونصوصًا حتى عند تعطيله. احذف البيانات الحساسة قبل مشاركة السجلات.
