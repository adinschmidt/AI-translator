# البدء

1. [ثبّت الإضافة](/ar/installation) وافتح الإعدادات من أيقونتها.
2. في الوضع الأساسي اختر OpenAI أو Anthropic أو Google وأدخل مفتاح API. يفرض المزود رسوم الاستخدام بشكل منفصل.
3. اختر لغة الهدف أو أدخل لغة مخصصة. تُحفظ التغييرات تلقائيًا؛ انتظر تأكيد الحفظ.
4. حدّد نصًا في صفحة HTTP أو HTTPS واضغط **ترجمة**. يظهر الزر عندما يتعرف الكشف المحلي على لغة مختلفة عن الهدف.

يتيح الوضع المتقدم [مزودين](/ar/providers) آخرين وOllama المحلي ونماذج مخصصة وإعدادات الاستدلال. راجع [الاستخدام](/ar/usage) لمعرفة الفرق عن قائمة النقر بالزر الأيمن.
