# الخصوصية

آخر تحديث: 20 سبتمبر 2026.

لا توجد خدمة ترجمة خلفية أو تحليلات يديرها مطور الإضافة. تُرسل النصوص المحددة أو مناطق الصفحة والتعليمات مباشرة إلى نقطة الاتصال المختارة. يعالج المزودون البعيدون البيانات وفق سياساتهم؛ وقد يمرر OpenRouter الطلبات لمزودين آخرين. قد يرسل طلب قائمة النماذج مفتاحك دون بدء ترجمة.

تستخدم المفاتيح والإعدادات `chrome.storage.sync`، وقد ينسخها المتصفح إلى أجهزة أخرى مسجّل الدخول عليها. التخزين ليس محليًا حصرًا ولا خزنة أسرار مستقلة. لا يوجد سجل ترجمة دائم، لكن النتائج تبقى في الصفحة والنوافذ والذاكرة المؤقتة.

عنوان Ollama الافتراضي هو `http://localhost:11434`. تبقى المعالجة محلية فقط إذا لم يمرر الخادم والنموذج الطلبات خارجيًا. تستقبل نقاط الاتصال المخصصة المحتوى وبيانات الاعتماد. لا يشفر HTTP النقل، بينما يشفره HTTPS.

يحاول الحجب التلقائي اكتشاف البريد والهواتف وSSN وSIN قبل الإرسال، وقد يفوّت معلومات. تُستبدل قيم سمات HTML المحاطة بعلامات اقتباس بعناصر نائبة وتُستعاد محليًا. قد تشمل السجلات المفاتيح والإعدادات والنص الأصلي والبيانات الوصفية والترجمات حتى دون تصحيح الأخطاء. حجب مدخلات API لا ينظف جميع السجلات.

يضيف `contextMenus` الإجراءات، ويحقن `scripting` السكربتات، ويحفظ `storage` المفاتيح والتفضيلات. يتيح `https://*/*` و`http://*/*` الوصول إلى الصفحات والمزودين. تعمل السكربتات في الإطارات المطابقة، وتبدأ ترجمة الصفحة في الإطار الرئيسي فقط. يكشف ELD اللغة محليًا ويُضمّن DOMPurify مع الإضافة.

يمكنك تغيير المزود وحذف المفاتيح أو بيانات الإضافة وإيقاف الترجمة. قد تحتفظ المزامنة بنسخ؛ والإيقاف لا يسحب البيانات المرسلة. راجع سياسة المزود واحذف المعلومات الخاصة قبل فتح [بلاغ](https://github.com/adinschmidt/AI-translator/issues).
