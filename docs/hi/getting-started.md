# शुरुआत करें

1. [एक्सटेंशन इंस्टॉल करें](/hi/installation) और उसके आइकन से सेटिंग्स खोलें।
2. बेसिक मोड में OpenAI, Anthropic या Google चुनकर API कुंजी डालें। प्रदाता उपयोग का शुल्क अलग लेता है।
3. लक्ष्य भाषा चुनें या कस्टम भाषा लिखें। सेटिंग्स अपने आप सेव होती हैं; पुष्टि की प्रतीक्षा करें।
4. HTTP या HTTPS पेज पर टेक्स्ट चुनकर **अनुवाद** दबाएँ। स्थानीय पहचान जब लक्ष्य से अलग भाषा पहचाने, तभी बटन दिखता है।

एडवांस्ड मोड में अन्य [प्रदाता](/hi/providers), स्थानीय Ollama, कस्टम मॉडल और रीजनिंग सेटिंग्स मिलती हैं। राइट-क्लिक मेन्यू से अंतर के लिए [उपयोग](/hi/usage) देखें।
