# トラブルシューティング

- ソースではなく `dist/chrome/` または `dist/firefox/manifest.json` を読み込みます。Firefox は 142 以降が必要です。ビルド後に拡張機能とページを再読み込みし、設定の保存確認を見てください。
- 完全な URL を使うか、エンドポイントを既定値に戻します。リモート接続は HTTPS を使います。401/403 はキー、アクセス権、課金を確認します。
- モデル一覧を更新するか、利用可能な ID を入力します。推論エラーなら上書きをオフにします。「API returned no translation text」なら別のモデルや短い文章を試します。一部の空の応答は非ストリーミングで再試行されます。
- クォータ回復を待つか、モデルを変えます。ページ翻訳は複数回リクエストし、再試行には待機時間があります。「停止」で実行を中止できます。
- Ollama を起動し、`ollama pull llama3.2` でモデルを取得し、`http://localhost:11434` を使います。オリジン拒否時は `OLLAMA_ORIGINS` を設定して再起動します。`OLLAMA_ORIGINS="*" ollama serve` は全オリジンを許可します。
- ボタンがない場合は設定と検出言語を確認します。詳細モードの翻訳先や追加指示には選択ボタンを使ってください。部分翻訳されたページは再読み込みで戻せます。

デバッグはエラー詳細を追加します。オフでもコンソールにキーや本文が含まれるため、ログ共有前に機密情報を除いてください。
