# 使い方

テキストを選択して「翻訳」を押すか、右クリックの選択テキスト翻訳を使います。結果は通常、選択元のフレーム内のウィンドウに順次表示されます。ボタンはローカル言語検出が成功し、翻訳先と異なる言語で、機密入力欄以外の場合に表示されます。

閉じるボタンまたは外側のクリックで閉じます。ウィンドウ保持を有効にすると複数の結果を残せます。処理中のウィンドウを閉じるとストリームを中止します。

ページ翻訳は最上位フレームの領域をバッチ処理し、完了した結果から反映します。埋め込みフレームを個別のページとして翻訳せず、画像やフォーム部品も対象外です。「停止」は翻訳済み部分を残します。元に戻すにはページを再読み込みします。動的な内容は未翻訳のまま残る場合があります。

選択ボタンは翻訳先と追加指示を使います。右クリックとページ翻訳は保存済み指示により英語になる場合があります。[設定](/ja/settings)を参照してください。ブラウザー内部ページや保護されたストアページではスクリプトが制限されます。
