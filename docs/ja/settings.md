# 設定

拡張機能のアイコンから開きます。変更は自動保存されます。表示言語は翻訳先とは別で、12 言語またはブラウザーの言語を選べます。テーマはライト、ダーク、システムです。

基本モードは OpenAI、Anthropic、Google に対応します。詳細モードは 11 プロバイダーに対応し、キー、モデル、エンドポイント、推論設定をプロバイダー別に保存します。モードごとに翻訳先を保持し、初期値は英語です。カスタム言語も入力できます。基本モードで保存すると、そのプロバイダーのモデルとエンドポイントは既定値に戻ります。

モデル更新はプロバイダーの一覧を取得します。プロバイダー、キー、エンドポイントの変更時にも取得する場合があります。失敗時は組み込み候補を表示します。絞り込みやモデル ID の直接入力も可能です。既定値ボタンは対応する欄だけを戻します。

選択範囲の横のボタンは、翻訳先と詳細モードの追加指示を使用します。例は「専門用語を維持する」です。右クリックとページ翻訳は保存済みのプロバイダー指示を使用し、追加指示を適用せず、詳細モードの翻訳先にも必ずしも従いません。英語になる場合があります。

詳細モードの **Override reasoning** は `none`、`minimal`、`low`、`medium`、`high`、`xhigh` を選べ、初期選択は `low` です。オフならプロバイダーの既定動作を使います。基本モードでは上書きしません。対応しないレベルは無視または拒否される場合があり、推論を増やすと料金や待ち時間が増えることがあります。拡張機能は出力トークン上限を設定しませんが、プロバイダー側の制限は適用されます。

詳細設定には選択ボタン、初期値オン、複数の翻訳ウィンドウの保持、オフ、機密データのマスキング、オン、デバッグ、オフがあります。マスキングは一部のメール、電話番号、米国 SSN、カナダ SIN を検出しますが、漏れがあります。マスクされた本文は翻訳後も戻りません。

キーと設定は `chrome.storage.sync` でデバイス間同期される場合があります。デバッグがオフでもログにキーや本文が含まれます。[プライバシー](/ja/privacy)を確認してください。
