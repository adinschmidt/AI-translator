# 用法

选中文本后点击“翻译”，或在右键菜单中选择“翻译选中文本”。结果通常逐步显示在选区所在框架的弹窗中。按钮要求本地检测成功、源语言与目标不同，且选区不在敏感输入字段中。

点击关闭按钮或弹窗外部可关闭窗口。开启保留窗口选项后可保留多个结果。关闭正在翻译的窗口会取消其流式请求。

“翻译页面”在顶层框架中分批处理文本区域，逐步应用结果，不会将嵌入框架作为独立页面翻译，也不翻译图片或表单控件。“停止”会保留已经完成的译文；刷新网页可恢复原文。动态内容可能保留未翻译状态。

选区按钮使用目标语言和额外指令，右键菜单与整页翻译则可能因保存的提供商指令而回退到英语。详见[设置](/zh/settings)。浏览器内部页面和受保护的扩展商店页面会限制脚本运行。
