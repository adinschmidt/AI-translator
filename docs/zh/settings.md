# 设置

点击扩展图标打开设置，修改会自动保存。界面语言与翻译目标语言独立，可选择 12 种语言或跟随浏览器。主题可选浅色、深色或跟随系统。

基本模式提供 OpenAI、Anthropic 和 Google。高级模式支持 11 个提供商，分别保存密钥、模型、端点和推理设置。两种模式各自保留目标语言，初始为英语，也支持自定义语言。在基本模式下保存会恢复该提供商的默认模型和端点。

“刷新模型”会向提供商请求列表，切换提供商、密钥或端点时也可能获取列表。失败时显示内置建议。你可以筛选列表或直接输入模型 ID。“填充默认值”只重置对应字段。

选区旁的按钮使用目标语言和高级模式的额外指令，例如“保留专业术语”。右键菜单和整页翻译使用已保存的提供商指令，不应用这些额外指令，也不总是遵循高级模式的目标语言，因此可能翻译成英语。

高级模式中的 **Override reasoning** 可选择 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`，初始选项为 `low`。关闭时，推荐模型使用低成本翻译设置，其他模型使用提供商默认值。不支持的级别可能被忽略或拒绝。Qwen Flash 的 None 关闭思考，其他级别开启思考。 基本模式不应用推理覆盖。模型可能忽略或拒绝不支持的级别。增加推理可能增加费用和等待时间。扩展不设置输出 token 上限，但提供商和模型的限制仍然适用。

高级设置包含选区翻译按钮，默认开启；保留多个翻译窗口，默认关闭；敏感数据遮盖，默认开启；调试，默认关闭。遮盖可识别部分邮箱、电话、美国 SSN 和加拿大 SIN，但可能遗漏。被遮盖的正文不会在译文中恢复。

设置和密钥使用 `chrome.storage.sync`，可能跨设备同步。即使关闭调试，日志也可能包含密钥和正文。请查看[隐私](/zh/privacy)。
