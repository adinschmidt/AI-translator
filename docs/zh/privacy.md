# 隐私

更新日期：2026 年 9 月 20 日

扩展没有开发者运营的翻译后端或分析服务。选中文本或页面区域及翻译指令会直接发送至配置的端点。远程提供商按各自政策处理数据，OpenRouter 可能转发请求。查询模型列表也可能发送密钥，并不需要启动翻译。

密钥和设置保存在 `chrome.storage.sync` 中，浏览器可能将其复制到其他已登录设备。这不是仅限本机的存储，也不是独立的密钥保险库。扩展不保存持久的翻译历史，但结果会留在网页、弹窗和临时内存中。

Ollama 默认地址是 `http://localhost:11434`。只有服务器和模型不转发请求时，处理才完全留在本地。自定义端点会收到内容和凭据。HTTP 不加密传输，HTTPS 会加密。

默认开启的遮盖功能会在发送前尝试识别邮箱、电话、SSN 和 SIN，但可能遗漏信息。带引号的 HTML 属性值会替换成占位符，在本地恢复。即使关闭调试，日志也可能包含密钥、设置、原文、元数据和译文。对 API 输入进行遮盖并不会清除所有日志中的敏感数据。

`contextMenus` 添加菜单操作，`scripting` 注入脚本，`storage` 保存密钥与设置。`https://*/*` 和 `http://*/*` 用于网页访问和提供商请求。脚本在匹配的框架中运行，整页翻译只在顶层启动。ELD 在本地检测语言，DOMPurify 随扩展打包。

你可以更换提供商、删除密钥或扩展数据，以及停止翻译。同步服务可能保留副本，停止操作无法撤回已发送的数据。请查看提供商政策，提交[问题反馈](https://github.com/adinschmidt/AI-translator/issues)前删除私人信息。
