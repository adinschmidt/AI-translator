# 사용법

텍스트를 선택하고 **번역**을 누르거나 문맥 메뉴에서 선택한 텍스트 번역을 실행합니다. 결과는 보통 선택한 프레임의 창에 점진적으로 표시됩니다. 버튼은 로컬 감지가 성공하고 대상 언어와 다르며 민감한 입력 필드가 아닌 경우 나타납니다.

닫기 버튼이나 바깥 클릭으로 창을 닫습니다. 창 유지 설정을 켜면 여러 결과를 남길 수 있습니다. 진행 중인 창을 닫으면 번역 스트림이 취소됩니다.

페이지 번역은 최상위 프레임의 영역을 묶어서 처리하고 결과를 순차 적용합니다. 삽입된 프레임을 별도 페이지로 번역하지 않으며 이미지와 폼 컨트롤도 대상이 아닙니다. **중지**해도 완료된 번역은 남습니다. 원문은 페이지를 새로고침하면 복원됩니다. 동적 콘텐츠는 번역되지 않을 수 있습니다.

선택 버튼은 대상 언어와 추가 지침을 사용합니다. 문맥 메뉴와 페이지는 저장된 공급자 지침에 따라 영어로 돌아갈 수 있습니다. [설정](/ko/settings)을 참고하세요. 브라우저 내부 페이지와 보호된 스토어 페이지에서는 스크립트가 제한됩니다.
