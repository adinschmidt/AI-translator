# 문제 해결

- 소스 대신 `dist/chrome/` 또는 `dist/firefox/manifest.json`을 로드하세요. Firefox는 142 이상이 필요합니다. 빌드 후 확장 프로그램과 페이지를 새로고침하고 설정 저장을 확인하세요.
- 완전한 URL을 쓰거나 엔드포인트를 기본값으로 복원하세요. 원격 서비스에는 HTTPS를 사용하세요. 401/403이면 키, 권한, 결제를 확인하세요.
- 모델을 새로고침하거나 계정에서 사용 가능한 ID를 입력하세요. 추론 오류면 재정의를 끄세요. 'API returned no translation text'이면 다른 모델이나 짧은 텍스트를 시도하세요. 일부 빈 응답은 스트리밍 없이 재시도합니다.
- 할당량 회복을 기다리거나 모델을 바꾸세요. 페이지 번역은 여러 요청을 보내고 재시도 사이에 기다립니다. **중지**는 현재 실행을 취소합니다.
- Ollama를 실행하고 `ollama pull llama3.2`로 모델을 받으세요. 주소는 `http://localhost:11434`입니다. 출처가 거부되면 `OLLAMA_ORIGINS`를 설정하고 재시작하세요. `OLLAMA_ORIGINS="*" ollama serve`는 모든 출처를 허용합니다.
- 버튼이 없으면 설정과 감지 언어를 확인하세요. 고급 대상 언어와 추가 지침에는 선택 버튼을 사용하세요. 부분 번역된 페이지는 새로고침하세요.

디버그는 오류 상세 정보를 추가합니다. 꺼져 있어도 콘솔에 키와 콘텐츠가 포함될 수 있으므로 로그를 공유하기 전에 민감한 정보를 제거하세요.
