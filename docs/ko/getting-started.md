# 시작하기

1. [확장 프로그램을 설치](/ko/installation)하고 아이콘으로 설정을 엽니다.
2. 기본 모드에서 OpenAI, Anthropic 또는 Google을 선택하고 API 키를 입력합니다. 공급자가 사용료를 별도로 청구합니다.
3. 대상 언어를 고르거나 사용자 지정 언어를 입력합니다. 자동 저장 확인을 기다립니다.
4. HTTP 또는 HTTPS 페이지에서 텍스트를 선택하고 **번역**을 누릅니다. 로컬 감지가 대상과 다른 언어를 인식할 때 버튼이 나타납니다.

고급 모드에서는 다른 [공급자](/ko/providers), 로컬 Ollama, 사용자 지정 모델 및 추론 설정을 사용할 수 있습니다. 문맥 메뉴와의 차이는 [사용법](/ko/usage)을 참고하세요.
