# 개인정보

업데이트: 2026년 9월 20일

개발자가 운영하는 번역 서버나 분석 서비스는 없습니다. 선택 텍스트 또는 페이지 영역과 지침을 설정된 엔드포인트로 직접 보냅니다. 원격 공급자는 자체 정책에 따라 처리하며 OpenRouter는 다른 공급자에게 전달할 수 있습니다. 모델 목록 조회도 번역을 시작하지 않고 키를 보낼 수 있습니다.

키와 설정은 `chrome.storage.sync`를 사용합니다. 브라우저가 로그인한 다른 기기로 복사할 수 있으므로 기기 전용 저장소나 별도의 비밀 보관함이 아닙니다. 영구 번역 기록은 저장하지 않지만 결과는 페이지, 창, 임시 메모리에 남습니다.

Ollama 기본 주소는 `http://localhost:11434`입니다. 서버와 모델이 요청을 전달하지 않아야 로컬 처리가 유지됩니다. 사용자 지정 엔드포인트는 콘텐츠와 인증 정보를 받습니다. HTTP는 전송을 암호화하지 않고 HTTPS는 암호화합니다.

기본으로 켜진 정보 가림은 전송 전에 이메일, 전화번호, SSN, SIN을 찾지만 놓칠 수 있습니다. 따옴표로 둘러싼 HTML 속성값은 자리표시자로 바꾸고 로컬에서 복원합니다. 디버그가 꺼져도 로그에 키, 설정, 원문, 메타데이터, 번역이 포함될 수 있습니다. API 입력 가림이 모든 로그를 지우지는 않습니다.

`contextMenus`는 메뉴를 추가하고 `scripting`은 스크립트를 삽입하며 `storage`는 키와 설정을 저장합니다. `https://*/*`, `http://*/*`는 페이지 접근과 공급자 요청에 쓰입니다. 스크립트는 해당 프레임에서 실행되지만 페이지 번역은 최상위에서만 시작합니다. ELD는 로컬에서 언어를 감지하고 DOMPurify도 포함됩니다.

공급자를 바꾸거나 키와 확장 프로그램 데이터를 지우고 번역을 중지할 수 있습니다. 동기화 서비스에 사본이 남을 수 있으며 중지해도 이미 보낸 데이터를 회수할 수 없습니다. 공급자 정책을 확인하고 [문제 보고](https://github.com/adinschmidt/AI-translator/issues)에서 개인정보를 제거하세요.
