# 설정

확장 프로그램 아이콘으로 설정을 엽니다. 변경 사항은 자동 저장됩니다. 인터페이스는 12개 언어나 브라우저 언어를 사용하며 번역 대상 언어와 별개입니다. 테마는 밝게, 어둡게, 시스템 중에서 고릅니다.

기본 모드는 OpenAI, Anthropic, Google을 제공합니다. 고급 모드는 11개 공급자의 키, 모델, 엔드포인트, 추론 설정을 각각 저장합니다. 모드마다 대상 언어를 따로 유지하고 초기값은 영어입니다. 사용자 지정 언어도 가능합니다. 기본 모드에서 저장하면 해당 공급자의 모델과 엔드포인트가 기본값으로 돌아갑니다.

모델 새로고침은 공급자 목록을 요청합니다. 공급자, 키 또는 엔드포인트 변경 때도 목록을 불러올 수 있습니다. 실패하면 내장 추천을 보여줍니다. 필터링하거나 모델 ID를 직접 입력할 수 있습니다. 기본값 채우기는 해당 필드만 초기화합니다.

선택 영역 옆 버튼은 대상 언어와 고급 모드의 추가 지침을 사용합니다. 예를 들어 '전문 용어를 유지하세요'를 입력할 수 있습니다. 문맥 메뉴와 페이지 번역은 저장된 공급자 지침을 사용합니다. 추가 지침을 적용하지 않고 고급 대상 언어도 항상 따르지 않아 영어로 번역할 수 있습니다.

고급 모드의 **Override reasoning**은 `none`, `minimal`, `low`, `medium`, `high`, `xhigh`를 제공하며 초기 선택은 `low`입니다. 끄면 공급자의 기본 동작을 사용합니다. 기본 모드에서는 재정의하지 않습니다. 모델이 수준을 무시하거나 거부할 수 있으며, 추론을 늘리면 비용과 대기 시간이 증가할 수 있습니다. 확장 프로그램은 출력 토큰 상한을 설정하지 않지만 공급자의 제한은 적용됩니다.

고급 제어에는 선택 버튼, 기본 켜짐, 여러 창 유지, 꺼짐, 민감한 정보 가림, 켜짐, 디버그, 꺼짐이 있습니다. 가림은 일부 이메일, 전화번호, 미국 SSN, 캐나다 SIN을 감지하지만 누락할 수 있습니다. 가려진 본문은 번역 후에도 복원되지 않습니다.

키와 설정은 `chrome.storage.sync`를 통해 기기 간 동기화될 수 있습니다. 디버그가 꺼져도 로그에 키와 본문이 포함될 수 있습니다. [개인정보](/ko/privacy)를 확인하세요.
