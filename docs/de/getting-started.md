# Erste Schritte

1. [Installiere die Erweiterung](/de/installation) und öffne die Einstellungen über ihr Symbol.
2. Wähle im Basismodus OpenAI, Anthropic oder Google und trage deinen API-Schlüssel ein. Der Anbieter rechnet die Nutzung separat ab.
3. Wähle eine Zielsprache oder gib eine eigene ein. Änderungen werden automatisch gespeichert; warte auf die Bestätigung.
4. Markiere Text auf einer HTTP- oder HTTPS-Seite und klicke auf **Übersetzen**. Die Schaltfläche erscheint, wenn die lokale Erkennung eine andere Sprache als die Zielsprache erkennt.

Der erweiterte Modus bietet weitere [Anbieter](/de/providers), lokales Ollama, eigene Modelle und Reasoning-Einstellungen. Unterschiede zum Kontextmenü stehen unter [Nutzung](/de/usage).
